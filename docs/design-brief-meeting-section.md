Brefly(브레플리) 랜딩 페이지에 **회의록 소개 섹션**을 새로 만들어 줘.

⚠️ 먼저 알아 둘 것: 이 랜딩 페이지는 다른 도구로 만들어져서 네 프로젝트에 자료가 없어.
그래서 디자인 시스템을 아래에 전부 적어 뒀어. **앱 UI 시안 프로젝트와도 다른 디자인**이야
(그쪽은 macOS 앱 화면, 이건 웹 랜딩 페이지).

## 지금 페이지가 어떻게 생겼나

한 줄짜리 흰 배경 랜딩 페이지야. 섹션이 이 차례로 있어.

1. **히어로** — 큰 제목 + 설명 + 다운로드 버튼, 오른쪽에 **앱 화면을 재현한 목업**
   (녹음 중 창 + 결과 창, 파형 막대 21개). 아래에 작은 세 항목이 가로로 놓임.
2. **어떻게 쓰나요** (`#how`) — 3열 그리드. 각 칸은 `01/02/03` 번호 + 제목 + 설명.
3. **디테일** — 옅은 회색 배경(`#fbfbfc`) 위에 4열 그리드. 아이콘 + 제목 + 설명.
4. **AI 모델** (`#models`) — 3열 카드. 카드마다 제목 + 회색 배지 + 설명 + 아래쪽 조건 줄.
5. **릴리스 노트** — 좌우 2단(제목 / 카드 목록).
6. **다운로드** — 가운데 정렬, 회색 배경(`#f2f3f5`).

여기는 달라. 전문 용어는 안 쓴다 (비개발자가 읽어).

## 무엇을 소개해야 하나

앱이 원래 하던 일은 **"단축키를 누르고 말하면 AI 가 정리해서 커서 자리에 넣어 주는 것"**이야.
이번에 **회의록**이 붙었어. 분량이 커서 기존 섹션 하나로는 부족해.

### 회의록이 하는 일

시작하는 길이 셋이야.

| | 무엇을 담나 | 권한 |
| --- | --- | --- |
| **대면 회의** | 이 맥의 마이크로 그 자리의 말 | 추가 권한 없음 |
| **화상 회의** | 내 목소리 + 스피커로 나가는 상대 목소리 | 화면 기록 권한 |
| **녹음 파일** | 이미 가지고 있는 파일 | 추가 권한 없음 |

**화상 회의는 "나 / 상대"로 갈라 적어.** 마이크와 스피커 소리를 따로 받기 때문에,
누가 말했는지 알 수 있어. 대면은 마이크 하나라 아직 구분하지 못해.

**결과물**은 이렇게 나눠서 정리돼.
```
한 줄 요약 · 결정된 것 · 할 일 · 논의한 것 · 다음에 볼 것
```
받아쓴 원문도 시각(00:42 같은)과 함께 따로 볼 수 있어.

**속도** — 35분 녹음을 약 1분 50초에 받아 적어. 20분 회의는 약 1분 15초.

**녹음은 이 컴퓨터 안에 있어.** 받아쓰기를 이 맥 안에서 처리하고 인터넷으로 보내지 않아.
요약할 때만 받아 적은 **글**을 AI 모델로 보내고, 녹음 파일 자체는 밖으로 나가지 않아.
회의 내용이라 사람들이 제일 걱정하는 부분이라 꼭 드러나야 해.

**처음 쓸 때** 받아쓰기 모델(약 547MB)을 한 번 내려받아. 그다음부터는 인터넷 없이 돼.

**아직 안 되는 것** — 대면 회의는 누가 말했는지 구분하지 못해. 그리고 받아쓰기는 녹음이
끝난 뒤에 시작해(녹음하면서 실시간으로 받아 적지는 않아).

## 만들어 줬으면 하는 것

1. **회의록 섹션.** 기능 분량에 맞는 크기로. 지금 내가 만든 건 카드 세 장짜리라 너무 빈약해.
   히어로처럼 **결과를 보여 주는 목업**이 있어야 할 것 같은데, 그 판단도 맡길게.

2. **어디에 넣을지.** 지금은 `#how`(3단계) 다음에 뒀어. 더 나은 자리가 있으면 바꿔 줘.

3. **히어로를 손대야 하는지도 봐 줘.** 지금 히어로는 받아쓰기만 말해
   ("말하면, Brefly가 정리해서 바로 입력합니다"). 앱이 하는 일이 둘이 됐는데 히어로가
   하나만 말하는 게 맞는지, 아니면 바꿔야 하는지 의견을 줘. 바꾼다면 시안도 같이.

4. **"어떻게 쓰나요" 3단계와 겹치지 않게.** 그 섹션은 받아쓰기 흐름이야. 회의록도 단계로
   설명하면 같은 모양이 두 번 나와서 지루해져.

## 지켜야 할 것

- **밝은 모드만.** 이 페이지는 어두운 모드가 없어.
- **코랄은 아껴 써.** 지금 페이지 전체에서 점 하나와 포커스 테두리에만 쓰여. 이 섹션에서
  갑자기 많이 쓰면 페이지가 따로 놀아.
- **1072px 폭 안에서.** 좁은 화면(휴대폰)도 생각해 줘 — 지금 3열 그리드들은 좁아지면 쌓여.
- **아직 안 되는 것도 적어 줘.** 대면 회의 화자 구분이 안 된다는 것. 받아 보고 기대와
  다르면 그게 더 나빠. 어디에 어떻게 적을지는 네가 정해 줘.
- 아이콘은 **lucide-react** 를 써 (지금 페이지가 그걸 쓰고 있어).
